# RB-03 Viewer
RB-Avionics Remote Viewer and Controller for Android

### Requirements
1. Android device shall be already connected to RB-01 or RB-03
2. WiFi is trusted = you can open the http://192.168.10.1 with Chrome

# Features
1. Support multiple Android display
2. On each screen the Viewer opens the website at full screen

## Remote display
- Primary display: http://192.168.10.1/RB-01
- Secondary display: http://192.168.10.1/RB-01
